# Technical Debt Register

Record deliberate compromises here. Do not use this file as a backlog for ordinary feature ideas.

Each item should include:

- ID;
- subsystem;
- what is incomplete/compromised;
- why deferred;
- current risk;
- trigger/milestone for correction;
- owner/status if the project uses ownership.

## Active items

None at bootstrap.

## Template

```md
### TD-XXX — Short title

- Subsystem:
- Status: open | accepted | resolved
- Deferred because:
- Current risk:
- Expected correction:
- Trigger / target milestone:
- Related ADR/issues:
```

Do not hide security-critical deferred work only in source-code TODO comments.
